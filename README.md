## Requerimientos
+ NetBeans 19
+ JDK 17 (activarlo desde los ajustes de NetBeans: tools > options > Java > Java Shell. Seguir el mismo proceso para Maven siguiendo la misma ruta.)
+ Un contenedor de Docker corriendo Postgres, que use la contraseña 1234 (tal cual la práctica 1)
+ Construir la base de datos y poblarla usando los scripts DDL y DML en el directorio SQL.
